# Geospatial Analysis of Housing Values and Socioeconomic Factors (California)

Geospatial and statistical analysis of California housing data to examine relationships between socioeconomic factors, location, and median house values.  
Applies exploratory data analysis, ANOVA, and regression modelling to generate interpretable insights for data-driven decision-making.

## Objective

To investigate how **geographic and socioeconomic variables** influence median housing values in California by:

- Exploring spatial and statistical relationships in the dataset  
- Comparing housing value distributions across **income levels and ocean proximity**  
- Applying **ANOVA and regression modelling** to test significance and predictive relationships  
- Interpreting results to support **evidence-based socioeconomic insight**

---

## Dataset

- California housing dataset containing:
  - Median income  
  - Total rooms and households  
  - Housing age  
  - Ocean proximity categories  
  - Median house value  

- Includes **geographic context** enabling spatial interpretation of socioeconomic patterns.

---

## Methodology

- Data exploration and preprocessing using **R**
- Exploratory Data Analysis (EDA) to understand **feature distributions and correlations**
- **ANOVA and Welch ANOVA** to test group-level statistical differences
- **Linear regression modelling** to evaluate predictive relationships
- Visualisation of relationships between **income, location, and housing value**

---

## Key Insights

- **Median income** is the strongest predictor of housing value.  
- **Ocean proximity** significantly influences price distribution.  
- Statistical testing confirms **meaningful socioeconomic segmentation**.  
- Regression modelling demonstrates **clear predictive structure** in housing valuation.

These findings highlight the role of **statistical and spatial analysis in real-world economic understanding**.
